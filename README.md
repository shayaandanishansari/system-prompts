# system-prompts

Prompts for AI assistants. Pick the file that fits the task, fetch its raw URL and follow it.

- [`field-guide-visual-system.txt`](https://raw.githubusercontent.com/shayaandanishansari/system-prompts/main/field-guide-visual-system.txt): visual system for any HTML page or document, covering colours, type, a stylesheet and components. It sets how a page looks, not what it says.
- [`conversation-replay.txt`](https://raw.githubusercontent.com/shayaandanishansari/system-prompts/main/conversation-replay.txt): replays the conversation above it as a compressed, chronological re-experience, covering opening context, a staged timeline, the through-line, end state and open threads. Returns one plain-text file and invents nothing.
